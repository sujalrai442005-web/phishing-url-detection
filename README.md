# Phishing URL Detection - Mini Project

**Status: In Progress**

This is a mini project for detecting phishing URLs based on their structural features.

## Work completed so far
- Loaded and cleaned the phishing URL dataset
- Removed duplicate rows
- Performed exploratory data analysis (EDA) using describe(), nunique(), and null checks
- Generated an automated EDA report using ydata-profiling

## Next steps
- Feature engineering
- Model training and evaluation
- Deploy a live demo

## Tech Stack
Python, Pandas, ydata-profiling
